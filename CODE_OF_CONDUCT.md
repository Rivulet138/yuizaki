# Code of Conduct

Yuizaki is committed to a welcoming, respectful, and technically rigorous community.

## Expected behavior

- Be respectful and assume good faith.
- Discuss code, evidence, and user impact rather than people.
- Give actionable feedback and explain tradeoffs.
- Respect privacy, licensing, and security boundaries.
- Make participation accessible across experience levels and backgrounds.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, deliberate disruption, credential disclosure, malicious code, and attempts to bypass project security boundaries are not acceptable.

## Enforcement

Report conduct concerns privately to the project maintainers. Include the relevant link or artifact, a concise description, and any safety considerations. Maintainers may remove comments, restrict participation, or close contributions when necessary to protect the community.

## Scope

This code applies in project spaces, issue trackers, pull requests, discussions, and project-related communication.
