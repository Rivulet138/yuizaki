# 面板切换与保存等待优化（2026-11-10）

本轮针对“切换面板、保存卡顿和等待过长”直接修改代码。保留工作区此前的功能修复及未提交改动，不改动真实用户设置、记忆或会话数据。浏览器验收拦截所有真实写入；保存耗时使用内存 HTTP fixture。

## 实现

- `AppShell.vue`：面板壳首次需要时挂载，之后跨聊天导航保留 KeepAlive 容器；聊天路由不进入行政面板缓存。聊天舞台按工作区缓存一个实例，其他面板仍为最多12个；切换工作区不会混用舞台状态。增加路由加载提示并清理相应钩子。
- `BrowserStageView.vue`、`BrowserPetStage.vue`、`pet-renderer.ts`：隐藏时停止轮询、尺寸拟合、输入监听、Pixi ticker 和 VRM 渲染；激活后恢复并重新测量尺寸。已加载模型保留，晚到的加载结果不得在隐藏阶段继续初始化或提交；聊天组件继续遵守原有路由挂载条件。
- `SettingsPanel.vue`：主设置直接加载，不等待授权状态、桌面绑定和管理历史；辅助数据按当前子页获取。离开子页后停止自动发现、资源进度跟踪和其他后续探测；相同配置复用已发现模型。
- 保存队列：空闲时停止编辑350 ms发送；持续编辑最长等待1000 ms；显式 flush 立即发送。在途保存结束后立即提交已合并的后续修改。分别显示待保存、正在保存、后续更改排队；保留失败重试、草稿和凭据删除保护。
- 后端运行时：前次模型重载占用运行锁时，将最新已提交的完整 section 快照排队，保存响应不再等待前次初始化完成。每轮固定revision，防止旧任务标记新配置已生效；连续编辑合并为最新意图，覆盖A→B→A，失败和取消可明确重试，vault凭据同步仍保持等待客户端重建的边界。
- 设置接口：保存响应携带与 GET 相同语义的脱敏 `normalized_settings`，由事务内快照产生，不增加落盘后读取。前端优先使用该快照，旧后端继续执行一次 GET 回读。
