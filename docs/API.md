# API reference

The default Python service is `http://127.0.0.1:8001`. Electron exposes a local control proxy at `http://127.0.0.1:38945`; launcher port fallback may change either value. Protected routes use the session token generated by the launcher.

## Settings and resources

`/api/settings` supports `GET /`, `PATCH /`, `GET /metadata`, `GET/DELETE /history`, `GET /export`, `POST /import`, `POST /rollback`, `POST /test/llm`, `POST /test/tts`, `POST /llm/models`, `GET /llm/status`, `POST /tts/warmup`, and `GET /tts/status`.

Electron resource routes include `/api/system/resources`, `/prepare`, `/cancel`, `/remove`, provider-specific prefetch routes, `/api/system/storage`, `/api/system/storage/cleanup`, and backup targets/create/restore routes.

## Voice and vision

Realtime voice uses Socket.IO events for session configuration, audio input, ASR partial/final transcripts, response deltas, TTS chunks, playback completion, and interruption. TTS payloads may include `duration_ms`; the renderer maps it to `durationMs` and falls back to browser media duration for legacy payloads.

Vision routes are explicit (`/vision/ocr` and Agent screenshot request events). A request has one capture and one analysis; there is no polling endpoint for continuous screenshots.

## Job event envelope

Tool, MCP, scheduler, heartbeat, and visual operations use a common event shape containing `jobId`, `runId`, `sessionId`, `kind`, `status`, timestamps, progress, summary, artifact references, and error/cancellation data. Terminal states are `completed`, `failed`, `cancelled`, `interrupted`, or `discarded`. UI projections may coalesce progress events but must retain terminal events.

## Avatar commands

Avatar control is intent-level: behavior state, idle profile, gaze target, expression mix, motion request, viseme/lip-sync, visibility, opacity, scale, dock, and model reload. Live2D/VRM adapters own smoothing and release timing.
